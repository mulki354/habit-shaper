## Instruksi

### Langkah 1: Install Validation Dependencies (jika belum)
- `npm install class-validator class-transformer`

### Langkah 2: HabitsModule Structure
Buat folder `backend/src/habits/` dengan file:
- `habits.module.ts` — import PrismaModule
- `habits.controller.ts` — CRUD endpoints, semua pakai JwtAuthGuard
- `habits.service.ts` — logika bisnis CRUD
- `dto/create-habit.dto.ts` — `{ name: string, type: "BUILD" | "BREAK" }`
- `dto/update-habit.dto.ts` — `{ name: string }` (tipe TIDAK bisa diubah)

### Langkah 3: Endpoint Details

**GET /habits** (Protected)
- Return semua habit milik `req.user.id`
- Untuk sekarang return data mentah, stats ditambahkan di Task 1.5

**POST /habits** (Protected)
- Body: `{ name, type }` — validasi type harus "BUILD" atau "BREAK"
- Set `userId` dari token
- Return: habit baru

**PATCH /habits/:id** (Protected)
- Body: `{ name }` — hanya nama yang bisa diubah
- Validasi: habit harus milik `req.user.id` (404 jika bukan)
- Return: habit terupdate

**DELETE /habits/:id** (Protected)
- Validasi: habit harus milik `req.user.id` (404 jika bukan)
- Cascade delete entries juga (sudah dihandle oleh Prisma onDelete: Cascade)
- Return: 204 No Content

### Langkah 4: Ownership Guard Pattern
- Di setiap endpoint yang butuh `:id`, cari habit dengan `{ id, userId }` — jika null, throw NotFoundException
- Ini memastikan user A tidak bisa akses/ubah/hapus habit user B

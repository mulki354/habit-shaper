## Instruksi

### Langkah 1: Install Dependencies
- `npm install @nestjs/jwt @nestjs/passport passport passport-jwt bcrypt`
- `npm install -D @types/passport-jwt @types/bcrypt`

### Langkah 2: AuthModule Structure
Buat folder `backend/src/auth/` dengan file:
- `auth.module.ts` — import JwtModule, PassportModule, PrismaModule
- `auth.controller.ts` — 3 endpoint (register, login, me)
- `auth.service.ts` — logika register, login, validasi password
- `dto/register.dto.ts` — `{ email: string, password: string }` dengan class-validator
- `dto/login.dto.ts` — `{ email: string, password: string }`
- `strategies/jwt.strategy.ts` — PassportStrategy(Strategy) untuk extract user dari token
- `guards/jwt-auth.guard.ts` — AuthGuard('jwt')

### Langkah 3: Endpoint Details

**POST /auth/register**
- Validasi email format, password minimal 6 karakter
- Cek email belum terdaftar (409 Conflict jika sudah)
- Hash password dengan bcrypt (saltRounds: 10)
- Buat user di DB
- Generate JWT token
- Return: `{ user: { id, email }, accessToken }`

**POST /auth/login**
- Cari user by email (401 jika tidak ditemukan)
- Compare password dengan hash (401 jika salah)
- Generate JWT token
- Return: `{ accessToken }`

**GET /auth/me** (Protected)
- Pakai JwtAuthGuard
- Return: `{ id, email }` dari req.user

### Langkah 4: JWT Configuration
- Secret dari env `JWT_SECRET`
- ExpiresIn: `'7d'` (cukup untuk testing)
- Payload: `{ sub: user.id, email: user.email }`

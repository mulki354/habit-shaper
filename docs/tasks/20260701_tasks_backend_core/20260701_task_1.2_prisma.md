# Task 1.2: Setup Prisma + Schema + Auto-Migration

**Status:** ⬜ Belum mulai
**Mengacu:** `docs/PRD_HabitShaper.md` § 3, `docs/implementations/20260701_implementation_backend.md`

---

## Instruksi

### Langkah 1: Install Prisma
- `cd backend && npm install prisma @prisma/client`
- `npx prisma init --datasource-provider mysql`
- Ini akan membuat `backend/prisma/schema.prisma` dan update `.env`

### Langkah 2: Tulis Schema
- Edit `backend/prisma/schema.prisma` sesuai PRD § 3:
  - Model `User` (id, email unique, passwordHash, createdAt, habits[])
  - Enum `HabitType` (BUILD, BREAK)
  - Model `Habit` (id, userId, name, type, createdAt, updatedAt, entries[])
  - Enum `EntryKind` (COMPLETED, RELAPSED)
  - Model `HabitEntry` (id, habitId, date @db.Date, kind, createdAt, @@unique([habitId, date]))

### Langkah 3: Buat Migration Awal
- `npx prisma migrate dev --name init`

### Langkah 4: PrismaModule (NestJS)
- Buat `backend/src/prisma/prisma.module.ts` dan `backend/src/prisma/prisma.service.ts`
- PrismaService extends PrismaClient, implements OnModuleInit
- Export PrismaModule sebagai global module

### Langkah 5: Auto-Migration di Container Startup
- Update `backend/Dockerfile` — copy folder `prisma/` ke image
- Update startup command: `npx prisma migrate deploy && node dist/main.js`
- Bisa pakai shell script `start.sh` atau langsung di CMD

### Langkah 6: Update compose.yml (jika perlu)
- Pastikan `DATABASE_URL` env var sudah di-pass ke backend service

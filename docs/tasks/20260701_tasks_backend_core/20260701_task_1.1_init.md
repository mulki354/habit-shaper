## Instruksi

### Langkah 1: Inisialisasi NestJS Backend
- Jalankan `npx @nestjs/cli new backend --package-manager npm --strict`
- Pastikan folder `backend/` terbentuk dengan struktur NestJS standar

### Langkah 2: Healthcheck Endpoint
- Tambahkan endpoint `GET /health` di `AppController` yang return `{ status: 'ok' }`

### Langkah 3: Backend Dockerfile
- Buat `backend/Dockerfile` — multi-stage (install deps → build → run)
- Startup command: `node dist/main.js` (nanti di Task 1.2 akan ditambah prisma migrate)

### Langkah 4: Compose.yml
- Buat `compose.yml` di root dengan 3 service:
  - `mysql` — MySQL 8, named volume, healthcheck
  - `backend` — build dari `backend/`, depends_on mysql healthy, port 4000
  - `frontend` — placeholder (image nginx:alpine, port 3000) — akan diganti di Task 2.1

### Langkah 5: Environment Files
- Buat `.env.example` di root sesuai PRD § 2.3
- Buat `.env` (copy dari `.env.example` dengan nilai yang sama — untuk local dev)

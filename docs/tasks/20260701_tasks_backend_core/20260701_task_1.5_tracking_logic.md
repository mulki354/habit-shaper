## Instruksi

### Langkah 1: Tambah Endpoints di HabitsController

Tambahkan 3 endpoint baru:
- `POST /habits/:id/complete`
- `POST /habits/:id/relapse`
- `GET /habits/:id/stats`

### Langkah 2: DTO
- `dto/entry.dto.ts` — `{ date?: string }` (opsional, default hari ini, format YYYY-MM-DD)

### Langkah 3: POST /habits/:id/complete

- Validasi: habit harus milik user DAN bertipe BUILD → 400 jika BREAK
- Parse `date` (default: hari ini dalam timezone server)
- Insert `HabitEntry` dengan kind `COMPLETED`
- Unique constraint `[habitId, date]` — handle duplicate → 409 "Already marked for this date"
- Return: entry baru + `currentStreak` terbaru

### Langkah 4: POST /habits/:id/relapse

- Validasi: habit harus milik user DAN bertipe BREAK → 400 jika BUILD
- Parse `date` (default: hari ini)
- Insert `HabitEntry` dengan kind `RELAPSED`
- Unique constraint → 409 jika sudah ditandai
- Return: entry baru + `cleanStreak` terbaru (ter-reset)

### Langkah 5: Logika Perhitungan Streak (CRITICAL — ikuti PRD § 3.1 persis)

**BUILD — currentStreak:**
```
Hitung mundur dari hari ini (atau kemarin jika hari ini belum ditandai).
Selama ada HabitEntry berkind COMPLETED di tanggal berurutan tanpa jeda.
Berhenti di jeda pertama.
```

**BUILD — weeklyCompletionRate:**
```
Dalam 7 hari terakhir (termasuk hari ini):
completedDays = jumlah entry COMPLETED
rate = completedDays / 7
missedDays = 7 - completedDays
```

**BREAK — cleanStreak:**
```
baseDate = MAX(tanggal relapse terakhir, createdAt habit)
cleanStreak = selisih hari antara baseDate dan hari ini
Jika belum pernah relapse → baseDate = createdAt
```

### Langkah 6: GET /habits/:id/stats

- Return detail:
  - `habit` (nama, tipe, createdAt)
  - `entries` (list semua entry, sorted by date desc)
  - `currentStreak` atau `cleanStreak` (tergantung tipe)
  - `weeklyCompletionRate` (hanya untuk BUILD)
  - `weeklyBreakdown` (7 hari terakhir: tanggal + status completed/missed/relapsed)

### Langkah 7: Update GET /habits

- Endpoint `GET /habits` (dari Task 1.4) sekarang harus include computed stats:
  - BUILD: `currentStreak`, `weeklyCompletionRate`
  - BREAK: `cleanStreak`

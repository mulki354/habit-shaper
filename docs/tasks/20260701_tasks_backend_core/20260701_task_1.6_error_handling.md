## Instruksi

### Langkah 1: Global Validation Pipe

Di `backend/src/main.ts`, aktifkan:
```typescript
app.useGlobalPipes(new ValidationPipe({
  whitelist: true,        // strip property yang tidak ada di DTO
  forbidNonWhitelisted: true, // error jika ada property asing
  transform: true,        // auto-transform tipe
}));
```

### Langkah 2: Global Exception Filter (Opsional tapi Direkomendasikan)

Buat `backend/src/common/filters/http-exception.filter.ts`:
- Catch semua HttpException
- Return format JSON konsisten:
```json
{
  "statusCode": 400,
  "message": "Validation failed",
  "errors": ["email must be an email", "password is too short"],
  "timestamp": "2026-07-01T..."
}
```

### Langkah 3: CORS

Di `backend/src/main.ts`:
```typescript
app.enableCors({
  origin: process.env.FRONTEND_URL || 'http://localhost:3000',
  credentials: true,
});
```

Tambahkan `FRONTEND_URL` ke `.env.example` jika belum:
```
FRONTEND_URL=http://localhost:3000
```

Dan update `compose.yml` — pass `FRONTEND_URL` ke backend service.

### Langkah 4: Review & Cleanup
- Pastikan semua DTO sudah pakai decorator class-validator (@IsEmail, @IsString, @IsEnum, @MinLength, @IsOptional, dll)
- Pastikan semua endpoint return format yang konsisten
- Pastikan error message informatif (bukan generic "Internal Server Error")

## Instruksi

### Langkah 1: Inisialisasi React + Vite
- Dari root: `npm create vite@latest frontend -- --template react-ts`
- `cd frontend && npm install`

### Langkah 2: Install & Konfigurasi Tailwind CSS
- `npm install -D tailwindcss @tailwindcss/vite`
- Konfigurasi di `vite.config.ts` — tambah plugin `@tailwindcss/vite`
- Import Tailwind di `src/index.css`:
  ```css
  @import "tailwindcss";
  ```

### Langkah 3: Struktur Folder
Buat struktur dasar:
```
frontend/src/
├── pages/          # Halaman (Login, Register, Dashboard)
├── components/     # Komponen reusable
├── lib/
│   └── api.ts      # HTTP client wrapper untuk fetch ke backend
├── App.tsx
├── main.tsx
└── index.css
```

### Langkah 4: API Client Base
Buat `frontend/src/lib/api.ts`:
- Base URL dari `import.meta.env.VITE_API_URL`
- Helper function untuk GET, POST, PATCH, DELETE dengan Bearer token
- Handle response errors secara konsisten

### Langkah 5: Frontend Dockerfile
Buat `frontend/Dockerfile`:
- Stage 1: build dengan Vite (`npm run build`)
- Stage 2: serve dengan nginx (copy dist ke `/usr/share/nginx/html`)
- Atau: pakai `vite preview` untuk dev (lebih simpel)

### Langkah 6: Update compose.yml
- Ganti service `frontend` dari `nginx:alpine` placeholder ke build dari `./frontend`
- Pass env `VITE_API_URL` saat build

### Langkah 7: Test Tailwind
- Tambah 1 elemen dengan class Tailwind di App.tsx (misal `<h1 className="text-3xl font-bold text-emerald-500">Habit Shaper</h1>`)
- Pastikan styling ter-apply

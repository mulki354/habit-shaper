## Instruksi

### Langkah 1: Install React Router
- `cd frontend && npm install react-router-dom`

### Langkah 2: Setup Router
Di `App.tsx`, setup routes:
```
/login     → LoginPage
/register  → RegisterPage
/dashboard → DashboardPage (protected)
/          → redirect ke /dashboard jika login, /login jika tidak
```

### Langkah 3: Auth Context/State
Buat `frontend/src/lib/auth.tsx` (atau context):
- State: `accessToken`, `user` (id, email)
- `login(token)` — simpan token di state + localStorage
- `logout()` — hapus token, redirect ke /login
- `isAuthenticated` — cek apakah token ada
- Load token dari localStorage saat app init (survive refresh)

### Langkah 4: Protected Route Component
Buat `frontend/src/components/ProtectedRoute.tsx`:
- Jika `isAuthenticated` → render children
- Jika tidak → redirect ke `/login`

### Langkah 5: Halaman Register
`frontend/src/pages/RegisterPage.tsx`:
- Form: email, password, confirm password
- Submit → `POST /auth/register`
- Sukses → simpan token, redirect ke `/dashboard`
- Error → tampilkan pesan (email sudah terdaftar, dll)

### Langkah 6: Halaman Login
`frontend/src/pages/LoginPage.tsx`:
- Form: email, password
- Submit → `POST /auth/login`
- Sukses → simpan token, redirect ke `/dashboard`
- Error → tampilkan pesan (email/password salah)

### Langkah 7: Link antar halaman
- Di Login: "Belum punya akun? Register"
- Di Register: "Sudah punya akun? Login"

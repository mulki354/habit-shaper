## Instruksi

### Langkah 1: Dashboard Page
Buat `frontend/src/pages/DashboardPage.tsx`:
- Fetch `GET /habits` saat mount (dengan Bearer token)
- Render daftar habit sebagai cards

### Langkah 2: Habit Card Component
Buat `frontend/src/components/HabitCard.tsx`:
- Tampilkan: nama habit, tipe (badge BUILD/BREAK), stats
- **BUILD card:**
  - Warna aksen: hijau tosca / emerald
  - Tampilkan: current streak (🔥), weekly completion rate (misal "5/7 hari")
- **BREAK card:**
  - Warna aksen: merah lembut / rose
  - Tampilkan: clean streak (hari bersih sejak terakhir relapse / sejak mulai)

### Langkah 3: Layout Dashboard
- Header: "Habit Shaper" + nama user + tombol logout
- Grid/list cards
- Tombol "Tambah Habit Baru" (belum fungsional, ditangani Task 2.4)

### Langkah 4: Visual Streak Badge
- Streak angka besar, bold
- Icon api 🔥 untuk BUILD streak
- Icon ✨ atau 💪 untuk BREAK clean streak
- Badge tipe: hijau "BUILD" / merah "BREAK"

## Instruksi

### Langkah 1: Tombol Mark Done (BUILD)
Di setiap HabitCard bertipe BUILD:
- Tombol "✅ Mark Done Today"
- Klik → `POST /habits/:id/complete` (tanpa body, default hari ini)
- Sukses → refresh stats, streak bertambah
- **Disabled** jika hari ini sudah ditandai (cek dari data entries/stats)
- Visual feedback: tombol berubah jadi "✅ Done!" (disabled, warna hijau)

### Langkah 2: Tombol Mark Relapse (BREAK)
Di setiap HabitCard bertipe BREAK:
- Tombol "⚠️ I Relapsed"
- Klik → **konfirmasi dulu**: "Tandai relapse hari ini? Streak akan reset ke Day 0."
- Confirm → `POST /habits/:id/relapse`
- Sukses → refresh stats, streak reset ke 0
- **Disabled** jika hari ini sudah ditandai relapse

### Langkah 3: Visual Feedback Setelah Aksi
- BUILD setelah mark done:
  - Streak number animasi naik (opsional, minimal angka berubah)
  - Weekly rate ter-update
  - Tombol disabled sampai besok

- BREAK setelah relapse:
  - Streak reset ke 0 — tampilkan state yang jelas (bukan cuma angka berubah diam-diam)
  - Misal: badge "Reset — Day 0" dengan warna merah
  - Tombol disabled untuk hari ini

### Langkah 4: Deteksi "Sudah Ditandai Hari Ini"
- Dari response `GET /habits` atau `GET /habits/:id/stats`, cek apakah ada entry untuk hari ini
- Jika sudah ada → tombol disabled + label berubah
- Bisa juga handle dari response 409 (Conflict) jika backend return duplicate error
